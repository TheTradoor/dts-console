# Security policy

This is a public-test-key development prototype, not a live-funds signer.
All included seeds and public keys are published test vectors. Never fund them.

Use a private vulnerability report on GitHub if that feature is enabled for
this repository. Otherwise contact the maintainer through a contact route
listed on their public profile and ask for a private reporting channel before
sharing exploit details. This document does not imply private reporting is
currently configured or promise a response time.

Include the affected commit, synthetic reproduction, expected and actual
behavior, and whether the issue concerns the Console, bridge, upstream firmware
or a future hardware assumption. Do not send real keys or private transactions.

Read docs/THREAT_MODEL.md for the current boundary. Upstream findings should be
coordinated with the relevant maintainer. Do not imply a flaw has been reviewed,
fixed or independently audited without the corresponding evidence.
